# نظام الجدولة المدرسية الذكي (School Timetable Scheduler)

منصة ذكية وشاملة لإدارة وجدولة الحصص المدرسية وتوزيع الجداول تلقائياً وبأعلى كفاءة، معتمدة على خوارزميات الذكاء الاصطناعي وبحوث العمليات (Google OR-Tools CP-SAT Solver).

---

## 🌟 مميزات النظام

- **لوحة تحكم حديثة (Modern Dashboard):** واجهة مستخدم متناسقة بتصميم عصري (Dark Emerald Sidebar + Light Workspace).
- **محرك جدولة ذكي (CP-SAT Solver):** حل أصعب تعارضات الجداول وتوزيع الحصص بالتساوي على المعلمين والفصول دون أي تضارب.
- **إدارة كاملة للمدرسة:**
  - هيكلية المراحل والصفوف والشعب الدراسية.
  - تحديد المواد ونصابات الحصص الأسبوعية.
  - تسجيل المعلمين وحصصهم وأيام الإجازات المحظورة.
  - إسناد الحصص للمعلمين وإدارة المهام.
- **تصدير وطباعة متقدمة:** تصدير الجداول المدرسية وجداول المعلمين والفصول إلى ملفات **Excel** و **PDF**.
- **دعم محلي وسحابي:**
  - يعمل محلياً بسلاسة عبر **WampServer (Apache + PHP + Python)** دون الحاجة لشاشات Terminal مفتوحة.
  - مزامنة سحابية وحفظ البيانات عبر **Firebase (Firestore & Authentication)**.

---

## 🚀 متطلبات التشغيل

1. **Python 3.10+** مع المكتبات التالية:
   ```bash
   pip install ortools
   ```
2. **WampServer** (أو أي خادم أباتشي محلي يدعم PHP).

---

## 💻 التثبيت والتشغيل المحلي (عبر WAMP)

1. استنسخ المشروع في المسار المحلي الخاص بك:
   ```bash
   git clone https://github.com/<your-username>/scheduler.git
   ```
2. قم بربط المشروع بمجلد خادم الويب (Directory Junction):
   ```cmd
   mklink /J "C:\wamp64\www\scheduler" "C:\مشروع الجدولة"
   ```
3. افتح المتصفح على الرابط:
   ```
   http://localhost/scheduler/
   ```
